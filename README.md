## Dateiorganisation

Die Startfolie als Vorlage für die Erstellung von Zusammenstellungen sowie die thematischen Einheiten liegen als *.md-Dateien auf erster Ebene. Die Dateien sind nach folgendem Muster benannt:

**Markdown/LiaScript-Bausteine für Präsentation**:
[xx_x]\_[TtL-FDM]\_[Inhalt-der-Folien]\_[A oder I].md

Dabei gilt:

- [xx_x] = Kapitel-ID

  - 00_ = Startfolie (Vorlage für Zusammenstellung einer vollständigen Präsentation)
  
  - 01_x = Einstiegsphase
  - 01_1 =
  - 02_x = Orientierung im Thema
  - 03_x = Arbeitsphase I: Didaktik
  - 04_x = Arbeitsphase II: FDM
  - 05_  = Wrap-Up / Zusammenfassung
  - 06_x = Abschlussphase
  - 07   = Quellen

- [TtL-FDM] = Workshopkürzel: Train-the-Lecturer zum Forschungsdatenmanagement
- [Inhalt-der-Folien] = Thematischer Inhalt
- [A oder I] = Vermittlungsform

  - A = Aktivität/Aufgabe
  - I = Input

**Zusammenstellungen für konkrete Durchführungen**

Für eine neue Zusammenstellung der Einheiten wird eine Kopie von 00_TtL-FDM.md angelegt (ebenfalls erste Ebene), und nach folgendem Muster benannt:

[Datum-der-Durchführung]_[Ort/Einrichtung-der-Durchführung]_TtL-FDM.md z.B. 2026-03-05_WissWB_TtL-FDM.md

WissWB = Wissenschaftliche Weiterbildung der CAU
